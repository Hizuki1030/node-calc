# node-calc

計算のまとまりをノードとして並べ、スライダーで振り、結果から逆に解き、Excel に書き出すツール。

```bash
npm install
npm run dev     # http://localhost:5180
```

AIによるブロック設計を使う場合は `.env.example` を `.env` にコピーし、
`ANTHROPIC_API_KEY` を設定してから開発サーバーを起動する。APIキーはブラウザへ渡さず、
Viteのサーバー側からAPIを呼び出す。呼び先はClaude直結が既定だが、`AI_API_STYLE=openai` と
`AI_API_BASE` を設定すればLiteLLMプロキシ経由で他ベンダーへ振り分けることもできる（詳細は `.env.example`）。

Tailscale 越しに他の端末（iPad など）から開く場合は、`server.host` を開けてあるので
`http://<このマシンの tailscale IP>:5180` でそのまま繋がる。

## 考え方: ノード = ミニ表計算ブロック

ノードは「1 演算」ではなく「電池残量計算」のような**意味のあるまとまり**。
1 つのブロックが、名前付きの入力ポートと、上から順に評価される計算行を持つ。

```
┌─ 電池残量計算 ────────────────────┐
│ ● 容量mAh          2000          │  入力ポート。式の中で名前で参照する
│ ● 消費電流mA         35          │
│ ● 経過時間h           4          │
│ ─────────────────────────────  │
│ 消費量mAh = 消費電流mA*経過時間h    │  中間行。次の行から名前で参照できる
│ 残量mAh   = MAX(容量mAh-消費量mAh,0) ● │  ◉出力 を押した行が出力ポートになる
│ 残量パーセント = ROUNDDOWN(…,0)   ● │
└──────────────────────────────┘
```

加算や切り上げのような単純なノードも、計算行が 1 本のブロックとして同じ仕組みで動く。
ブロックはヘッダの **↧** ボタンでライブラリに保存でき、左のパレットから何度でも置ける。

ノードは 4 種類:

| | 役割 |
|---|---|
| **入力変数**（アンバー） | 値・範囲・刻み・単位。スライダーで振る。逆算の未知数になる |
| **ブロック**（ティール） | 上記のミニ表計算 |
| **結果**（朱） | 値の表示と、逆算の**目標値** |
| **モニター**（青） | 入力された値をそのまま表示 |

配線は出力ポート → 入力ポートをドラッグ。線をクリックすると外れる。
入力ポートは 1 本だけ受けるので、つなぎ直すと差し替わる。

## 式の書き方

Excel の関数をそのまま書く。識別子は日本語が使える（`容量mAh` など）。

- 演算子 `+ - * / ^ %` と括弧、比較 `> >= < <= = <>`
- 丸め `ROUNDUP(x,桁) ROUNDDOWN(x,桁) ROUND(x,桁) INT(x) TRUNC(x,桁)`
- 単位丸め `CEILING(x,単位) FLOOR(x,単位)` — 5 mm 単位、100 円単位など
- 数値 `ABS SQRT POWER MOD EXP LN LOG10 PI()`
- 選択 `MIN MAX IF(条件,真,偽)`

丸めは Excel の定義に合わせてある（`ROUNDUP` は 0 から遠ざかる方向、`CEILING.MATH` は +∞ 方向、
`MOD` は除数の符号に従う）。二進小数の桁落ちで 1 つずれないよう相対 ε を入れている。

ブロックの計算エディターには、1行につき `{結果変数} = 式` と記述する。入力や上の行の結果は
`{変数名}` の形で参照でき、複数行は上から順に評価される。たとえば
`{面積} = {幅}*{高さ}` の次の行で `{価格} = {面積}*{単価}` と書ける。
「外部へ出力」を有効にした行はそれぞれ独立した出力ポートになる。式はKaTeXで整形表示する。

## 単位チェック

入力変数・ブロックの入力・計算行の単位は必須。最終結果とモニターの単位は接続元から自動取得する。右側の「単位」タブでグラフ全体を検査する。
`mm`、`mm^2`、`m/s`、`kg*m/s^2` のように書ける。無次元は `1`。
加減算では同じ単位、乗除算では合成された次元、接続では送り側と受け側の単位を検査する。

## スイープ

変数を 1 つ選んで min〜max を振り、結果の動きを折れ線で見る。
切り上げが入る計算は階段状になる。スライダーの現在値は縦線で重ねて出る。

## 逆算

結果に目標値を入れ、未知数にする変数を選ぶ。他の変数は現在値で固定し、未知数を
`min` から `max` まで、その変数に設定した「刻み」ずつ変化させる。各候補の結果と目標値の差を比較し、
最も差が小さいパラメーター値を返す。完全一致する候補がなくても、刻みに乗る値の中で最も近い候補と
実際の結果・目標との差を表示する。同じ近さの候補が複数ある場合は、現在値に最も近いものを優先する。
候補数に上限は設けず、件数が多い探索は小分けに処理して進捗バーと中止ボタンを表示する。

## Excel への書き出し

`.xlsx` は **1 ノード = 1 セクション**で、中間計算も 1 行ずつ残る。

```
     A            B                        C                      D
 3   ■ 入力変数
 4   全長         3000                     範囲 0 〜 10000        mm
 5   板幅         455                      範囲 100 〜 1000       mm

 8   ■ 枚数と金額
 9   全長mm       =$B$4                    ← 全長
12   必要枚数     =ROUNDUP(($B$9/$B$10),0)  = ROUNDUP(全長mm/板幅mm,0)   枚
13   合計金額     =($B$12*$B$11)            = 必要枚数*単価              円

16   ■ 結果
16   合計金額     =$B$13                    ← 合計金額             円 / 目標 12000
```

- **B 列が生きたセル**。青い入力セルを書き換えると下の計算と結果がそのまま追従する
- **C 列**にはノードに書いた式を名前のまま残してあるので、どの行が何の計算か追える
- Excel の `=-2^2` は 4 になる（単項マイナスが `^` より強い）ため、書き出す式は必ず括弧で守る。
  剰余 `%` は Excel では後置のパーセント演算子なので `MOD()` に書き換える

TSV コピー（Excel に ⌘V で貼れる）と、グラフ定義の JSON 保存 / 読込もある。
グラフは localStorage に自動保存される。

## 構成

```
src/engine/parser.ts     式 → AST（評価と Excel 生成で共有）
src/engine/functions.ts  Excel 互換の丸めなど
src/engine/evaluate.ts   AST 評価 + グラフのトポロジカル評価・循環検出
src/engine/solve.ts      スイープ / 逆算（範囲解 + 二分法）
src/engine/excel.ts      AST → Excel 式、セル割り当て
src/export/xlsx.ts       最小 OOXML ライタ（fflate で zip）
src/nodes/               3 種のノード UI
src/panels/              パレット・変数・スイープ・逆算・書き出し
```
